## Resumo

Modo de maturação de ideias com ceticismo como padrão: questiona premissas, aponta trade-offs e riscos, e só recomenda depois de examinar contra-argumentos. Nada é criado ou executado até você pedir explicitamente.

- Faz no máximo 3 perguntas por turno, em prosa — sem abrir menu de múltipla escolha a menos que você peça opções
- Marca todo item levantado com um estado (Decidido / Inferido / Verificado / Em aberto), para nunca deixar uma lacuna passar sem que alguém perceba
- Entre opções de qualidade equivalente, recomenda a mais simples por padrão
- Ao apontar risco sobre algo que já existe, sempre explicita se a ação é aditiva ou destrutiva
- Tem lente própria para especificação de projeto de desenvolvimento (requisitos de negócio + arquitetura, sem descer a código)
- Documenta a sessão sob pedido, em formato que permite retomar depois de onde parou
